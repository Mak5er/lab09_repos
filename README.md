## Опис завдань (Варіант 23)

### Завдання № 9.1: Простори імен
Табулювання функції, заданої рядом Тейлора, на інтервалі від $x_{\text{поч}}$ до $x_{\text{кін}}$ з кроком $dx$ та точністю $\varepsilon$:
$$e^{x^2} = \sum_{n=0}^{\infty} \frac{x^{2n}}{n!} = 1 + x^2 + \frac{x^4}{2!} + \frac{x^6}{3!} + \frac{x^8}{4!} + \dots, \quad |x| < \infty$$

Проєкт розділено на окремі модулі з відокремленням інтерфейсу (`.h`) від реалізації (`.cpp`) та інкапсуляцією ресурсів у власних просторах імен (`nsVar`, `nsDod`, `nsSum`).

### Завдання № 9.2.1: Директиви препроцесора (Частина 1)
Обчислення виразу $w$ із застосуванням директив умовної компіляції препроцесора (`#if`, `#elif`, `#else`, `#endif`) та макросів у власному заголовному файлі `macros.h`:
$$w = \begin{cases} \max\left(|x| + |y| + |z|, \, x^3\right), & 1 < z < 3 \\ \min\left(2x + y, \, (2y - z)^2\right), & z > 3 \end{cases}$$

### Завдання № 9.2.2: Директиви препроцесора (Частина 2)
Перевірка прямокутності трикутника та доведення співвідношення між катетами $a, b$ та висотою $H$, проведеною до гіпотенузи:
$$\frac{1}{H^2} = \frac{1}{a^2} + \frac{1}{b^2}$$
